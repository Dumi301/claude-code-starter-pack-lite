# The "deeper, not bigger" prompt

From Felix Rieseberg, who works on Claude at Anthropic, on his own blog: ["How to be more ambitious: A tutorial for humans with models"](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/), 13 October 2026, section Depth ("A simple prompt that often helps me:"). Copied verbatim. Not an official Anthropic prompt; not affiliated.

> I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I'm not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.

## How to use it
1. Paste it right after your task, or before the prompt you want improved.
2. Read the four answers: they name the raw data, the tools and the outside check you skipped.
3. Run the rewritten prompt, not your original one.

## As a Claude Code skill
[`skills/deeper/SKILL.md`](../skills/deeper/SKILL.md): copy the `deeper` folder to `~/.claude/skills/`, then type `/deeper <your task>`.
