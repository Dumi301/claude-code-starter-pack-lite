## What it does (from the README)
"One Claude plugin auto-generates CLIs for ANY codebase through proven 7-phase pipeline."
"CLI-Anything works on any software with a codebase."

## Setup (from the README, Claude Code section)
```
/plugin marketplace add HKUDS/CLI-Anything
/plugin install cli-anything
/cli-anything ./gimp
```
On Windows the README says Claude Code needs Git for Windows (bash + cygpath) or WSL for this plugin.
