# 5 free repos every Claude Code user should install

The list from the reel. Stars, licence and last push from the GitHub API on 2026-11-16; the quoted line is from each repo's own README.

1. **[anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official)**: Anthropic's official plugin directory. (47,457 stars · Apache-2.0 · last push 2026-11-16)

   > To install, run `/plugin install {plugin-name}@claude-plugins-official`
   > or browse for the plugin in `/plugin > Discover`

2. **[obra/superpowers](https://github.com/obra/superpowers)**: skills: brainstorm, plan, test, then code. (318,630 stars · MIT · last push 2026-11-03)

   > /plugin install superpowers@claude-plugins-official

3. **[upstash/context7](https://github.com/upstash/context7)**: up-to-date docs for your coding agent. (64,931 stars · MIT · last push 2026-11-16)

   > npx ctx7 setup

4. **[microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp)**: a real browser Claude can drive. (39,742 stars · Apache-2.0 · last push 2026-11-16)

   > claude mcp add playwright npx @playwright/mcp@latest

5. **[thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)**: memory that carries across sessions. (117,642 stars · Apache-2.0 · last push 2026-11-16)

   > /plugin marketplace add thedotmack/claude-mem
   > /plugin install claude-mem
