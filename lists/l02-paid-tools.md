# 4 free GitHub repos that replace paid AI dev tools

The list from the reel. Stars, licence and last push from the GitHub API on 2026-11-16; the quoted line is from each repo's own README.

1. **[anthropics/claude-code-action](https://github.com/anthropics/claude-code-action)**: an AI reviewer on your pull requests. (9,979 stars · MIT · last push 2026-11-16)

   > The easiest way to set up this action is through [Claude Code](https://claude.ai/code) in the terminal. Just open `claude` and run `/install-github-app`.

2. **[musistudio/claude-code-router](https://github.com/musistudio/claude-code-router)**: route Claude Code to any model. (38,188 stars · MIT · last push 2026-11-16)

   > npm install -g @musistudio/claude-code-router
   > ccr ui

3. **[siteboon/claudecodeui](https://github.com/siteboon/claudecodeui)**: Claude Code on your phone and the web. (14,643 stars · AGPL-3.0 · last push 2026-11-16)

   > npx @cloudcli-ai/cloudcli

4. **[ccusage/ccusage](https://github.com/ccusage/ccusage)**: token usage and cost from your local logs. (19,453 stars · see LICENSE · last push 2026-11-16)

   > npx ccusage@latest
